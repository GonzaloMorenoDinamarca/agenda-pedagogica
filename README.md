# Agenda Pedagógica

Libro docente para la tableta Boox Go 10.3 (tinta electrónica), Liceo A-1 de Arica.

- **Hoy:** cursos del día, pendientes de la última clase, asistencia bajo 75 %, disertaciones y equipos que requieren atención.
- **Asistencia:** lista ordenada por curso y apellido, P/A/T, observaciones, registro de clase, estadísticas, nómina (PDF, pegar lista o a mano).
- **Notas:** evaluaciones por curso o por nivel completo, promedios, CSV.
- **Clases:** todos los registros de clase con búsqueda y destacados.
- **Disertaciones:** equipos desde la nómina, rúbrica con criterios de equipo e individuales, cronómetro, notas que pasan a Notas.
- **Bitácora:** seguimiento de equipos de proyecto.

Funciona sin internet una vez instalada (Chrome › menú ⋮ › Instalar app). Los datos se guardan solo en la tableta; usa «Respaldo y datos» para descargar un respaldo semanal.

La app publicada está en la rama `gh-pages`.
